# Описание каждой функции с примерами вызова

## Функции

| Функция | Файл | Что делает? | Пример вызова: |
|---|---|---|---|
| **`square(n)`** | `square.py` | Принимает число `n`, возвращает его квадрат | `square(5)` => `25` |
| **`add_binary(a, b)`** | `add_binary.py` | Принимает два десятичных числа `a` `b`, возвращает их сумму в виде двоичной строки | `add_binary(7, 8)` => `'1111'` |

**Примечание:** функция `add_binary` возвращает `str`, а не `int`. 

## Пример использования

```python
from square import square
from add_binary import add_binary

print(square(5))         # => 25
print(add_binary(7, 8))  # => '1111'
```
